# Comprendre le projet pour la soutenance

Ce dossier accompagne un plan d'étude du code, séance par séance. Chaque fiche contient : un objectif, une explication appuyée sur de vrais fichiers et de vraies lignes, des exercices à faire sur l'application, des questions de contrôle avec leurs corrections.

## Méthode (à chaque séance)
1. Je vous explique le bloc.
2. Vous l'exécutez sur un vrai cas (par exemple le jeu `customer-accounts`).
3. Vous modifiez une valeur et vous observez.
4. Vous réexpliquez à voix haute, sans notes, en 3 minutes.

## Ordre si vous manquez de temps
Séances 0, 1, 2, 4, 5 et 9 couvrent l'essentiel de ce qu'un jury demande. Le graphe (8) et les corrections (7) viennent ensuite.

## Règle d'or
Une réponse que vous ne pouvez pas dire avec vos mots n'est pas comprise. Dans ce cas, revenez au code et demandez-moi de réexpliquer autrement.
